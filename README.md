# IBONDA — Agency Dashboard

لوحة إدارة الوكالات العقارية ضمن مشروع مستقل عن المستودع السابق.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديداً باسم `IBONDA-AGENCY-DASHBOARD`.
2. ارفع محتويات هذا المجلد إلى فرع `main` (المجلدات والملفات الموجودة داخله، وليس مجلد ZIP نفسه).
3. من Settings ثم Pages اختر GitHub Actions كمصدر للنشر.
4. بعد أول تشغيل ناجح لـ Actions سيكون الموقع على: `https://USERNAME.github.io/IBONDA-AGENCY-DASHBOARD/`

## ملاحظة وظيفية

الواجهة الحالية مبنية على بيانات تجريبية محلية. لم يتم ربطها بعد بقاعدة بيانات إنتاجية أو نظام صلاحيات متعدد الوكالات.
